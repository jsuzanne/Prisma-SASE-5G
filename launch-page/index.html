COMPONENT 01 · RADIO ACCESS NETWORK

5G RAN VM (UERANSIM + RAN Agent)

Emulates the 5G gNodeB base station (nr-gnb) and 5G User Equipment modems (nr-ue), controlled remotely by the Orchestrator via a lightweight RAN Agent API (:8081).

  • Dynamic UE Templating: Generates per-SIM ue-<imsi>.yaml configuration files with matching keys, APN/DNN, and S-NSSAI slice parameters.
  • Dedicated Tunnel Interfaces: Each active nr-ue process spawns an isolated Linux TUN interface (uesimtun0, uesimtun1…) with its own mobile IPv4 address.
  • N2 & N3 Radio Links: Connects to the 5G Core VM over N2 (NGAP/SCTP port 38412) for signaling and N3 (GTP-U UDP port 2152) for user plane packets.
COMPONENT 02 · 5G STANDALONE PACKET CORE

5G Core VM (Open5GS + MongoDB)

3GPP Release 17 5G Standalone Packet Core handling subscriber authentication, PDU session management, and GTP-U packet forwarding.

  • MongoDB Subscriber Store (:27017): Stores SIM credentials (IMSI, K, OPc), 5QI QoS profiles, AMBR bandwidth limits, and S-NSSAI network slices.
  • AMF & SMF Control Plane (:9090): Authenticates attaching UEs, assigns mobile IPv4 addresses (10.45.0.x), and exposes real-time JSON session telemetry.
  • UPF User Plane: Decapsulates GTP-U traffic from the RAN VM and forwards mobile flows over N6 toward Prisma SASE 5G.
COMPONENT 03 · ZERO-TRUST CLOUD SECURITY

Palo Alto Networks Prisma SASE 5G

Managed through Strata Cloud Manager (SCM), enforcing agentless Zero-Trust security policies on 5G devices based on SIM and hardware identity.

  • 5G Identity Mapping (/tenantUEInfo): Associates every SIM's IMSI, hardware IMEI, and APN with a dedicated Subscriber Security Group.
  • Live Session Correlation (/uesession/register): Maps dynamic PDU session IPs to 5G identities in real time so firewall rules track devices across IP changes.
  • Instant Policy Shifts: Moving a SIM from a Permissive group to a Restrictive group immediately updates L7 security enforcement without dropping the 5G session.

  • Step 1 · Provision: Orchestrator writes the SIM subscriber to Open5GS MongoDB and registers the 5G identity in Prisma SASE 5G.
  • Step 2 · Attach: RAN Agent starts nr-ue; Open5GS establishes the PDU session and allocates an IPv4 on uesimtunX.
  • Step 3 · Correlate: Orchestrator polls SMF telemetry and binds the live IPv4 to the SIM identity in Strata Cloud Manager.
  • Step 4 · Validate: Stigix 5G Lab generates application & threat traffic over the 5G user plane to validate Zero-Trust inspection.
