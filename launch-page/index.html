Stigix 5G Traffic & Security Lab

Stigix V3 validation platform that binds directly to the Linux tunnel interfaces (uesimtun0..N) of all emulated 5G devices (Mobile Users, Branches/POS, and IoT/OT) to inject traffic across the 5G network.

  • Per-Tunnel L4/L7 Traffic Injection (SO_BINDTODEVICE) Routes enterprise SaaS/HTTPS flows, Custom TCP, VoIP RTP streams (MOS/Jitter scoring), and Stateful PCAP replays directly through each emulated 5G UE's dedicated uesimtunX interface.
  • Zero-Trust Security & Threat Validation Executes URL category audits, DNS tunneling, EICAR malware downloads, Command & Control (C2) beacons, and AI/DLP security tests from any 5G SIM identity to verify SCM policy enforcement.
  • Web Wireshark & Live Packet Capture Captures and dissects packets on uesimtun* interfaces directly inside the browser alongside Digital Experience Monitoring (DEM) probes.
VM 1 · 10.10.10.2 · RADIO & TRAFFIC

Emulated 5G UEs & UERANSIM RAN VM

Powered by aligungr/UERANSIM ↗, emulating the 5G gNodeB base station (nr-gnb) and 5G User Equipment modems (nr-ue), controlled remotely by the Orchestrator via the RAN Agent API (:8081).

  • Emulated 5G Endpoints: Models Mobile Users (Smartphones/Laptops), 5G Branches/Retail POS, and IoT/OT Infrastructure (Robots, EV Chargers, CCTV) with dedicated eSIM profiles.
  • Isolated Tunnel Interfaces: Each active nr-ue process spawns a dedicated Linux TUN interface (uesimtun0, uesimtun1…) where Stigix injects real application and threat traffic.
  • VM 1 ⇄ VM 2 Links: Multiplexes all 5G UEs through nr-gnb to the Open5GS Core VM over N2 (NGAP/SCTP :38412) for control signaling and N3 (GTP-U :2152) for encapsulated user traffic.
VM 2 · 10.10.10.1 · PRIVATE 5G CORE

Open5GS 5G Core VM (5GC-CP & UPF)

3GPP Release 17 5G Standalone Packet Core (open5gs/open5gs ↗) paired with aligungr/UERANSIM ↗, handling subscriber authentication, network slicing, PDU session allocation, and N6 forwarding to Prisma SASE 5G.

  • 5GC-CP & MongoDB (:27017): Stores SIM credentials (IMSI, K, OPc), 5QI QoS profiles, AMBR limits, and S-NSSAI slices (SST/SD).
  • AMF & SMF Telemetry (:9090): Authenticates UEs over N2, allocates PDU session IPv4s (10.45.0.x), and exposes live session state to the Orchestrator.
  • UPF & SPI Forwarding: Decapsulates N3 GTP-U packets from VM 1 and routes user plane traffic over the SPI (Service Provider Interconnect) tunnel into Prisma SASE 5G.
SPI INTERCONNECT & ZERO-TRUST CLOUD

Prisma SASE 5G & Service Provider Interconnect (SPI)

Connects the Private 5G UPF to Prisma Access SPN Clusters over a high-bandwidth Service Provider Interconnect (SPI) while correlating AAA/REST identity metadata.

  • SPI (N6 IPsec Interconnect): Carries user data plane traffic directly from the 5G Core UPF into Prisma Access Service Processing Nodes (SPN Clusters).
  • SIM-Based Identity Enforcement: Enforces granular security rules based on Subscriber ID (IMSI/SUPI), Equipment ID (IMEI/PEI), Slice ID (SST/SD), and APN.
  • Advanced Security Stack: Inspects all 5G flows with DLP, IoT Security, DNS Security, Advanced Threat Prevention (ADV TP), Advanced URL Filtering (ADV URL), and WildFire (ADV WF).
CONTROL PLANE AUTOMATION

4-Way Ground-Truth State Reconciler

The Orchestrator continuously synchronizes all 4 layers of the lab so SIM state and IP bindings are always verified against ground truth:

  • 1 · Open5GS MongoDB: Verifies subscriber keys (K/OPc), APN, and S-NSSAI slice configuration on VM 2.
  • 2 · UERANSIM RAN Agent: Verifies active nr-ue processes and live uesimtunX interfaces on VM 1.
  • 3 · Open5GS SMF/AMF: Polls live PDU sessions and assigned mobile IPv4 addresses on VM 2.
  • 4 · Prisma SASE 5G (SCM): Pushes 5G identities (/tenantUEInfo) and registers live session IPs (/uesession/register).
